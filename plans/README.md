## Findings Considered and Rejected
- **Replacing chess.hpp with an external C library**: `chess.hpp` is a fast, robust bitboard engine that is already well integrated; replacing it would introduce unnecessary churn for zero functional gain.
- **Porting QML to QtWidgets**: The user specifically requested modern native Qt6 Quick SceneGraph with fluid animations and vector SVG graphics.
